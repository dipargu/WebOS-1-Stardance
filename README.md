<h1>diparguOS</h1>
<p>This is diparguOS, the new operating system.</p>
<p>This project is one of my first programming projects made in Visual Studio Code: I built an "OS" from scratch featuring basic functions, a graphical interface, smooth movable items, and a link to my Spotify playlist.</p>
<p>Note: The stopwatch has a slight delay when you click it, so keep that in mind.</p>
<p>To close apps, double-click on the icon of the app you want to close.</p>
